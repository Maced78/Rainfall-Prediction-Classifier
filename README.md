The Rainfall Prediction Classifier is a machine learning project designed to predict whether it will rain based on daily meteorological data. Using features such as temperature,
humidity, wind speed, and other weather parameters, the model can classify whether rainfall is likely or not.

This project demonstrates the full data science workflow: data preprocessing, exploratory data analysis,
model training, evaluation, and visualization of results. It serves as a showcase of predictive modeling skills suitable for a portfolio or CV.
